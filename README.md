A two-sleeve paper-trading bot for the pump.fun bonding-curve replay (agent-fun/replay/v2). The pullback sleeve buys a 3–12% dip after a real run-up, once the price has bounced 5% off its window low and fresh buys confirm it — small (0.03 SOL), never pyramided, exits fast. The runner sleeve buys only the strongest fresh breakouts (≥50% run-up in 20 slots on ≥5 SOL net inflow from ≥6 buyers) with 0.10 SOL and rides them on a wide stop and a 20% trailing stop. A 0.01 SOL probe mechanism keeps the run above the 20-coin guardrail. Deterministic, paper money only, no network access.

## Run it

```sh
node main.ts
```
